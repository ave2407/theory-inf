# Источники

## Задача 1.3 — основа реализации Хаффмана

- [Project Nayuki — Reference Huffman coding](https://github.com/nayuki/Reference-Huffman-coding),
  [исходный huffmancoding.py](https://github.com/nayuki/Reference-Huffman-coding/blob/master/python/huffmancoding.py),
  лицензия MIT. Исходник получен 25.10.2026; SHA-256:
  `3336cf2665f3428f91e2161781827ac1836d3cdc24d7efeafdce60268cb51169`.
- `theory_inf/huffman.py` адаптирует построение дерева из
  `FrequencyTable.build_code_tree`, канонические коды из `CanonicalCode`
  и битовый вывод из `BitOutputStream`. Сохранено разрешение равных весов
  по минимальному символу поддерева. Длины и кодовые слова сверены с
  исходником на 52 наборах частот: `results/task_1_3/reference_validation.json`.
- Изменения: убрана иерархия узлов и неиспользуемый универсальный интерфейс;
  обход дерева итеративный; пустой файл и один символ обрабатываются без
  фиктивных символов; для одного символа разрешено слово длины 0;
  битовый вывод принимает целое кодовое слово и буферизует байты.
- Цикл декодирования в `theory_inf/archive.py` основан на обходе дерева
  из `HuffmanDecoder`, но использует явное число полезных битов и исходный
  размер вместо маркера EOF. Контейнер ZMH1, CRC32, файловые операции,
  проверки структуры и статистика добавлены для данного задания.
- Copyright и уведомление о лицензии сохранены в исходнике адаптации;
  полный текст лицензии приведён ниже в этом файле.

Готовая реализация использована как основа по принятому решению. Это
не снимает запрета пункта 1.1 условия ДЗ на готовые реализации Хаффмана
и декодирования: при проверке соответствия этому пункту данное решение
нельзя считать самостоятельной реализацией.
