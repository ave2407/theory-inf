# Расширенный формат источника: спецификация, задача 1.1

Вариант s=2: k=3, M=4, L=5, d=3. Кодировка файлов UTF-8, синтаксис JSON.
Ниже описана спецификация; готовые полные файлы — `examples/task_1_1/`.

## Грамматика

```text
Source = {
  "models": { ModelName: Distribution(Symbol), ... },
  "switches": { SwitchName: Distribution(ModelName), ... },
  "source": [SwitchName, ...],
  "state_machine"?: {
    "initial": Distribution(StateName),
    "states": {
      StateName: {
        "source"?: [SwitchName, ...],
        "transitions": { Symbol: Distribution(StateName), ... }
      }, ...
    }
  }
}
Distribution(Name) = { Name: "rational", ... }
```

Имена — непустые строки. Все объекты распределений, models, switches, states
и списки source непустые. Алфавит — объединение символов всех моделей,
включая символы нулевой вероятности. Пропущенный в модели символ имеет
вероятность 0. Пропущенные веса в переключателе/initial/переходе также равны 0.
Переходы задаются для **каждого символа алфавита**, даже если он невозможен
в данном состоянии. Все ссылки должны существовать, включая ссылки с весом 0.

Вероятности — строки с целым числом, десятичной записью или дробью:
`"1"`, `"0.3"`, `"1/3"`. Сумма каждого распределения точно равна 1;
отрицательные значения и нулевой знаменатель запрещены. JSON-числа вместо
строк не принимаются. Повторяющиеся ключи и неизвестные поля — ошибки.

L — длина верхнего source. Длины source всех состояний равны L;
если source состояния отсутствует, используется верхний source.
Локальные периоды короче L выражаются повторением имён.
Параметры своего варианта не ограничивают файлы преподавателя.

## Семантика

Перед первым символом выбирается состояние Z₀ по initial. На такте t=0,1,…:

1. В состоянии z берётся переключатель `states[z].source[t mod L]`.
2. По переключателю выбирается модель, по модели — символ Xₜ₊₁.
3. После символа новое состояние выбирается по `transitions[z][Xₜ₊₁]`.

Все выборы условно независимы при известных состоянии, фазе и распределении.
Фаза общая для всей реализации; при переходе состояния она не сбрасывается.
Без state_machine существует одно неявное состояние с петлёй. Это в точности
исходный формат: модели выбираются заново каждый такт, прошлое не сохраняется.
Имена и поля JSON сортируются при компиляции распределений: перестановка
ключей не меняет реализацию при том же seed.

## Конструкции на собственном варианте

В пяти примерах три символа A,B,C и четыре модели: три детерминированные
и одна равномерная. Переключатели A,B,C задают циклические перестановки
распределения p=(13/24,7/24,4/24). Все source имеют длину 5.

| Файл | Конструкция и свойство |
|---|---|
| iid.json | source=[A,A,A,A,A], без состояния. Независимые одинаково распределённые символы: стационарность и эргодичность. |
| periodic.json | source=[A,B,C,A,B]. Маргинальные распределения меняются с фазой: нестационарность. |
| markov.json | 27 состояний — истории длины 3. В истории abc используется переключатель a, после x состояние bcx. initial равномерно по 27 историям. Это стационарный эргодический марковский источник глубины ровно 3. |
| nonergodic.json | В начале с вероятностями 1/2 выбирается regime_A или regime_B. Режим не меняется; в нём постоянно используется соответствующий переключатель. Смесь стационарна, но неэргодична. |
| deterministic.json | Всегда A; четыре модели и алфавит из трёх символов сохранены, B,C имеют нулевую вероятность. Вырожденный стационарный эргодический источник. |

У markov.json uniform initial стационарно: для каждого следующего контекста
вероятность входа равна (1/27)·Σₐpₐ(x)=1/27. Все эмиссии положительны,
поэтому любые две истории связаны за три шага; у AAA есть петля.
Неэргодичность смеси: предельная частота A равна 13/24 либо 4/24
в зависимости от сохранённого режима, тогда как ансамблевая вероятность A=17/48.

## Вероятности и частоты

Точная вероятность блока считается переносом вероятностной массы по состояниям
с фиксацией требуемых символов. Для блока со смещением j сначала делаются j
шагов с суммированием по всем символам. Начальное состояние не выбирается
заново в начале блока. Среднее из условия — (1/L)Σⱼ₌₀ᴸ⁻¹P(Xⱼ₊₁…Xⱼ₊ᵣ=word).

Для произвольного расширенного источника это среднее по первым L позициям;
оно не обязано быть пределом временной частоты. В частности, смесь сохраняет
случайно выбранный режим. Для исходного периодического формата частота
сходится к среднему по фазам.
