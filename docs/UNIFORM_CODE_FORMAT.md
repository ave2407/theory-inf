# Описание равномерного кода, задача 1.2

Файл `uniform-types-v1` — компактная спецификация всех кодов для n=1…n_max.
Он самодостаточен: содержит алфавит, точные вероятности, q и для каждого n
длину ℓ и количество выбранных блоков. Перечислять q^ℓ строк не требуется.

## Однозначное построение

1. Исключить символы нулевой вероятности. Порядок оставшихся символов задан
   полем alphabet (лексикографический порядок строк Python).
2. Для каждого вектора количеств (n₁,…,nₖ), Σnᵢ=n, вычислить вероятность
   одного блока ∏pᵢ^nᵢ. Сортировать типы по убыванию этой вероятности,
   при равенстве — по возрастанию самого вектора.
3. Внутри типа расположить блоки лексикографически по alphabet.
4. Взять первые selected_blocks блоков. Тип на границе может быть взят частично.
5. Блоку с рангом j, начиная с 0, назначить q-ичную запись j, дополненную
   слева нулями до ℓ цифр. Цифры — целые числа 0…q−1, кодовое слово — массив
   цифр, поэтому q может быть больше 10. При ℓ=0 кодовое слово — пустой массив.

Для декодирования вычисляется ранг по q-ичной записи и берётся блок с этим
рангом в том же порядке. Если ранг не меньше selected_blocks — ошибка.
Некодируемый исходный блок также даёт ошибку. Нулевые вероятности можно
не кодировать даже при свободных кодовых словах: вероятность ошибки от них 0.
Для практического вычисления ранга внутри типа используются количества
перестановок мультимножества; сам архиватор здесь не реализуется.

## Числа и округление

Вероятности и P_e — точные Fraction. Пусть pᵢ=aᵢ/D с общим знаменателем D.
Тогда вероятность блока имеет числитель ∏aᵢ^nᵢ и знаменатель D^n.
Все типы сравниваются по целому числителю, покрытая масса тоже складывается
целыми числами. Python int не имеет фиксированного переполнения; float
используется только для отображения результата. Вывод точных дробей не зависит
от ограничения Python на преобразование int длиннее 4300 цифр в строку.

Энтропия и логарифмы вычисляются Decimal с 80 значащими цифрами.
При вычислении энтропии добавляются рабочие разряды по размеру знаменателей,
чтобы вероятность (D−1)/D не округлялась до 1 до вычисления логарифма.
Известные рациональные значения обрабатываются точно: степени двойки,
для равномерного источника — рациональное log_q(|support|), а при R=H
также распределения p_i=q^(-r_i) с рациональными r_i. В последнем случае
H/log₂q=Σp_i r_i, что устраняет неоднозначность на целой границе.
Проверки численной различимости используют относительную погрешность,
чтобы корректно обрабатывать положительные скорости и энтропии малого порядка.
Вблизи границы округления точность повышается до 160 и 320 цифр;
если результат всё ещё не различим, выдаётся диагностика вместо округления
по произвольному допуску. `--rate H` задаёт точное равенство R=H.

## Проверка источника

Используется конечная линейная модель на парах (состояние, фаза).
Матрица T_a переносит массу после символа a, T=ΣT_a — без фиксации символа.
Сначала проверяется постоянство односимвольного распределения на линейной
оболочке initial, initial·T, … . Затем строится оболочка векторов initial·T_word
и для каждого проверяется v·T_a·1=p(a)·v·1. При замыкании базиса равенство
доказано для всех префиксов, поэтому источник iid, а значит стационарен.
Все операции здесь рациональные. Конечная проверка нескольких коротких
блоков такого доказательства не даёт. Неиспользуемые состояния не мешают
принимать файл, фактический выходной закон которого iid.
